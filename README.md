\# CLI File Manager



A menu-driven File Management System built using \*\*Bash Scripting\*\*.



This project provides a simple command-line interface to manage files and directories, perform backup operations, and retrieve file statistics.



\## Features



\- User authentication with a limited number of login attempts.

\- Create files and directories.

\- List directory contents.

\- Search for files (case-insensitive).

\- Copy files with overwrite confirmation.

\- Move and rename files.

\- Delete files with confirmation.

\- Create timestamped directory backups.

\- Display file statistics (lines, words, characters, and size).



\## Technologies Used



\- Bash Scripting

\- Git Bash

\- Linux Command-Line Utilities

\## How to Run



1\. Clone the repository:



```bash

git clone YOUR\_REPOSITORY\_URL

```



2\. Navigate to the project directory:



```bash

cd CLI-File-Manager

```



3\. Run the application:



```bash

bash main.sh

```
